# Web Development Learning Labs

A set of server-side web development labs demonstrating core concepts like form handling, authentication, and session management.

## 📂 Labs

1. **1_India-Info-mapping** — Data mapping practice
2. **2_Greeting-Invite** — Greeting/invite page logic
3. **3_SignUp** — User sign-up form and handling
4. **4_SignIn** — User sign-in / login flow
5. **5_SessionTracking** — Session management and tracking
6. **6_Student-Marksheet-Access** — Student marksheet access system

## 🛠️ Tech Stack

Html, Css, Js, Servlet / JSP (Java-based web development)

## 🎯 Purpose

A practice-focused repository for learning core web development concepts — authentication, session handling, and dynamic form-based applications.
